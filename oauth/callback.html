Is this safe?

Yes. This page contains no network code of any kind: its content security policy has no connect-src, so the browser will not permit it to transmit anything, to anyone, under any circumstances. The authorization code is read from your own address bar and displayed to you. It never leaves your browser.

The code is also single use and expires within minutes, and it cannot be exchanged for anything without the client secret, which stays on your own computer.

What to do

  1. Copy the code above.
  2. Return to your terminal, where ./health auth-whoop --manual is waiting.
  3. Paste it and press return.

If you would rather not copy by hand, paste the entire URL from your address bar instead. The tool accepts either.
